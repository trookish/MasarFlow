# MasarFlow v0.2.0.0 — P7: Vault — Obsidian-grade knowledge base

> **For Hermes:** execute with `subagent-driven-development`, one task at a time, two-stage review per task. Read the master plan (`…-master.md`) §1, §4 (D6), §6, §7 first. **Branch:** `release/v0.2.0`.
> **Depends on:** P1 (`src/lib/desktop/bridge.ts`, `desktop/src/shared/api.ts`), P2 (`src/lib/server/roots.ts` + `assertRootAllowed` inside `/api/fs/*`), P4 (`src/lib/db/dirty.ts`), P5 (`src/lib/entities/{registry,open}.ts`, Dexie v12 `activity`).
> **Does not depend on:** the Python service (P3 removes the gate), P6, P8.

**Goal:** Give every MasarFlow project a **real markdown mirror** — notes, docs, specs, tasks and daily notes written as plain `.md` files into a user-chosen folder, with a one-way push engine, a verify-before-overwrite import, an explicit never-silently-destroy conflict policy, frontmatter properties, a Ctrl/Cmd+O quick switcher and a daily-note core the P8 Today view opens.

**Architecture in one paragraph.** `src/lib/sync.ts` already holds the *pure* half of a sync engine (`hashContent`, `normalizeMd`, `parseFrontmatter`, `classifyRemoteStatus`, `reconcile`, `summarize`) and `syncFiles` (Dexie) already stores per-file `{path, hash, status, entityId, lastSyncedAt}` — but both transports today either talk to Obsidian's Local REST API (`/api/obsidian`) or *do nothing at all* (`handleSyncLocal` only relabels rows "synced" in the browser: `sync-view.tsx:163-180`). P7 adds the missing transport (direct disk writes through `/api/fs/{list,read,write}` with the root allow-list from P2) and turns the classification into an explicit **plan → execute** engine: pure `planVaultSync()` decides (`write` / `import` / `conflict` / `missing` / `repath` / `external` / `blocked` / `skip`), an injected `VaultIO` executes. All policy logic lives in node-testable `.ts` modules (`tests/vitest.config.ts` includes only `tests/unit/**/*.test.ts`, node env — finding A14); the UI is thin glue.

## 3. Decisions (with rejected alternatives)

- **D-P7-1 — What is mirrored.** `notes/**`, `docs/**`, `specs/**`, `tasks/**` + `daily/**.md` — the kinds a human *writes prose in* and would open in Obsidian/VS Code/git. **Not mirrored:** `devLogs` (generated, high churn), `memories` (AI-internal), `commits` (already a git projection), `activity` (derived), `sprints`/`systems`/`archNodes` (rollup/visual structures with no prose), `canvases` (`.canvas` JSON — master §7 cut line). *Rejected:* mirroring everything (churn, mailbox-files, 6 more codecs for zero user value).
- **D-P7-2 — One file format, two transports.** `sync.ts`'s `serializeNote`/`serializeDoc` delegate to the new `src/lib/vault/serialize.ts`, so a note mirrored to disk and the same note pushed to Obsidian over REST are byte-identical. *Rejected:* a second serializer for the vault (two formats to keep in sync = the #1 source of "why did my file change?").
- **D-P7-3 — Paths.** Mirror root = `<chosen folder>/MasarFlow/<project-slug>/` (`VAULT_SUBFOLDER` reused from `obsidian-client.ts`), so one Obsidian vault can host several MasarFlow projects without touching the rest of the vault. Inside it the layout is `notes/`, `docs/`, `specs/`, `tasks/`, `daily/`. **The recorded path in `syncFiles` wins**; a new entity's path is derived from its kind + folder chain. A file the user *moves* is re-adopted by its `msf_id` (never duplicated); a title change never renames a file.
- **D-P7-4 — Unknown frontmatter keys survive.** A new **non-indexed** `props` field on note/doc/spec/task holds every non-reserved frontmatter key (`cssclass`, `priority`, user fields…). Import merges them, export re-writes them. Known keys (`title type tags aliases created updated status priority number category progress day msf_*`) are reserved and always re-derived from the entity. No Dexie version bump (Finding A9).
- **D-P7-5 — Conflict policy (explicit, testable):**
  1. A file is overwritten **only** when its current content hash equals the hash we recorded at our last successful write (or when there is no file at all). Otherwise → `conflict`, no write, `hash` keeps the **base** so nothing is lost.
  2. The app entity is overwritten by a file **only** when the entity is unchanged since the last sync (`remote_modified`) — the verify-before-overwrite import. Both-changed is always `conflict`.
  3. A file deleted outside the app is never silently re-created (`missing` → status `deleted`; the UI offers "Re-create file").
  4. Conflicts are never auto-resolved: resolving is a user click (`keep app` / `keep file` / `re-create`), and `keep app` records the file's current hash as base *first*, so the overwrite is a deliberate, logged act.
  *Rejected:* last-write-wins (silently destroys work), and per-file diff UI (out of scope; the file is on disk — the user can open it).
- **D-P7-6 — Where the binding lives.** zustand `persist` key **`masarflow-vault`** (per-project `{root, folder, enabled, autoImport, lastRunAt}`); the per-file index stays in the existing `syncFiles` table. *Rejected:* a new Dexie `vaults` table (v14) — it would collide with P6's v13 bump on `src/lib/db/index.ts` for zero benefit; the binding is UI configuration, and losing it only costs one picker click because files + ids are on disk.
- **D-P7-7 — No new dependency.** The YAML subset Obsidian's Properties UI actually writes (scalars, quoted scalars, `[a, b]`, block lists) is ~90 lines, fully tested. *Rejected:* `js-yaml`/`gray-matter` (bundle weight, formatting surprises, and a second opinion about what our own files look like).
- **D-P7-8 — Quick switcher.** Ctrl/Cmd+O (free; Ctrl+K is the command palette — A/Finding), rank with the already-installed `fuse.js`, open via P5's `openEntity()`. *Rejected:* extending the command palette (P8 owns palette v2; a separate dialog keeps the contracts from colliding).

```ts
/**
 * The ONE frontmatter codec for MasarFlow's markdown vault.
 *
 * A deliberately small YAML subset: scalars, quoted scalars, `[a, b]` inline
 * lists and block lists — exactly what Obsidian's Properties UI writes for
 * text / number / checkbox / list properties. Nothing else is supported on
 * purpose: every unsupported line is preserved verbatim as part of the body
 * (never rewritten into something we cannot round-trip).
 */

export type PropValue = string | number | boolean | string[];

export interface Frontmatter {
  fields: Record<string, PropValue>;
  body: string;
}

/** Keys whose scalar form is a list (Obsidian tag / alias syntax). */
export const LIST_KEYS = new Set(["tags", "aliases"]);

const FENCE = /^---\n([\s\S]*?)\n---\n?/;
const BLOCK_ITEM = /^\s*-\s+/;
/** One path-hostile or YAML-hostile character (non-global: safe for `.test`). */
const RISKY_ONE = /[:#?*&!|>'"%@`{}[\],]/;
const RISKY_ALL = /[:#?*&!|>'"%@`{}[\],]/g;

function unquote(raw: string): string {
  const s = raw.trim();
  if (s.length >= 2 && ((s[0] === '"' && s.endsWith('"')) || (s[0] === "'" && s.endsWith("'")))) {
    const inner = s.slice(1, -1);
    return s[0] === '"' ? inner.replace(/\\"/g, '"').replace(/\\\\/g, "\\") : inner;
  }
  return s;
}

function scalar(raw: string): PropValue {
  const s = unquote(raw);
  if (s === "true" || s === "false") return s === "true";
  if (/^-?\d+(\.\d+)?$/.test(s)) return Number(s);
  return s;
}

/** Split a frontmatter block + body. Tolerant: never throws on user files. */
export function parseFrontmatter(md: string): Frontmatter {
  const norm = md.replace(/\r\n/g, "\n");
  const m = norm.match(FENCE);
  if (!m) return { fields: {}, body: norm.replace(/^\n+/, "") };
  const fields: Record<string, PropValue> = {};
  let key: string | null = null;
  let items: string[] | null = null;
  const flush = (): void => {
    if (key && items) fields[key] = items;
    key = null;
    items = null;
  };
  for (const line of m[1].split("\n")) {
    if (BLOCK_ITEM.test(line) && key) {
      const raw = line.replace(BLOCK_ITEM, "");
      items = [...(items ?? []), String(scalar(raw))];
      continue;
    }
    const at = line.indexOf(":");
    if (at === -1) continue;
    flush();
    const k = line.slice(0, at).trim();
    const rest = line.slice(at + 1).trim();
    if (!k) continue;
    if (rest === "") {
      key = k;
      items = [];
      continue;
    }
    if (LIST_KEYS.has(k)) {
      const list = rest.startsWith("[") && rest.endsWith("]") ? rest.slice(1, -1) : rest;
      fields[k] = list
        .split(",")
        .map((p) => String(scalar(p)).trim())
        .filter((p) => p !== "");
      continue;
    }
    if (rest.startsWith("[") && rest.endsWith("]")) {
      const inner = rest.slice(1, -1).trim();
      fields[k] = inner === "" ? [] : inner.split(",").map((p) => String(scalar(p)).trim());
      continue;
    }
    fields[k] = scalar(rest);
  }
  flush();
  return { fields, body: norm.slice(m[0].length).replace(/^\n+/, "") };
}

const RISKY = new RegExp(`(?:${RISKY_ONE.source})|^\\s|\\s$|^-`);

/** One value as YAML text. Quoted whenever YAML would misread it. */
export function yamlScalar(v: PropValue): string {
  if (typeof v === "number" || typeof v === "boolean") return String(v);
  const s = v;
  if (s === "") return '""';
  if (s === "true" || s === "false" || /^-?\d+(\.\d+)?$/.test(s) || RISKY.test(s) || s.startsWith("-")) {
    return `"${s.replace(/\\/g, "\\\\").replace(/"/g, '\\"')}"`;
  }
  return s;
}

/** Render a frontmatter block + body. Empty lists and undefined keys vanish. */
export function stringifyFrontmatter(
  fields: Record<string, PropValue | undefined>,
  body: string,
): string {
  const lines: string[] = ["---"];
  for (const [k, v] of Object.entries(fields)) {
    if (v === undefined) continue;
    if (Array.isArray(v)) {
      if (v.length === 0) continue;
      lines.push(`${k}:`);
      for (const item of v) lines.push(`  - ${yamlScalar(item)}`);
      continue;
    }
    lines.push(`${k}: ${yamlScalar(v)}`);
  }
  lines.push("---");
  const clean = body.replace(/\r\n/g, "\n").replace(/^\n+/, "").replace(/\n+$/, "");
  return `${lines.join("\n")}\n\n${clean}\n`;
}

/** Read a value as text (lists join with ", "). */
export function asString(v: unknown, fallback = ""): string {
  if (v === undefined || v === null) return fallback;
  if (Array.isArray(v)) return v.map(String).join(", ");
  return String(v);
}

/** Read a value as a list ("a, b" and ["a","b"] both work). */
export function asList(v: unknown): string[] {
  if (v === undefined || v === null) return [];
  if (Array.isArray(v)) return v.map(String);
  return String(v)
    .split(",")
    .map((s) => s.trim())
    .filter(Boolean);
}
```

```ts
const ILLEGAL_ALL = /[<>:"/\\|?*\u0000-\u001f]/g;
const ILLEGAL_ONE = /[<>:"/\\|?*\u0000-\u001f]/;
const DAY_RE = /^\d{4}-\d{2}-\d{2}$/;
const MAX_PATH = 240;

/** Windows/macOS/Linux-safe single segment. Keeps unicode letters. */
export function fileSegment(input: string, fallback = "untitled"): string {
  const cleaned = (input || "")
    .normalize("NFC")
    .replace(ILLEGAL_ALL, " ")
    .replace(/\s+/g, " ")
    .replace(/^[.\s]+/, "")
    .replace(/[.\s]+$/, "")
    .slice(0, 64)
    .trim();
  return cleaned || fallback;
}

/** Validate a mirror-relative path. Returns it unchanged when it is safe. */
export function assertRelativeVaultPath(rel: string): string {
  if (typeof rel !== "string" || rel.trim() === "") throw new VaultPathError("empty vault path");
  if (rel.length > MAX_PATH) throw new VaultPathError(`vault path too long (${rel.length} > ${MAX_PATH})`);
  if (rel.includes("\\")) throw new VaultPathError(`vault paths use forward slashes: ${rel}`);
  if (rel.startsWith("/") || /^[a-zA-Z]:/.test(rel)) throw new VaultPathError(`vault paths are relative: ${rel}`);
  for (const seg of rel.split("/")) {
    if (seg === "" || seg === "." || seg === "..") throw new VaultPathError(`illegal "${seg}" segment in: ${rel}`);
    if (ILLEGAL_ONE.test(seg)) throw new VaultPathError(`illegal character in path segment: ${seg}`);
    if (/[.\s]$/.test(seg)) throw new VaultPathError(`segment ends with dot/space: ${seg}`);
  }
  return rel;
}

export function joinVaultPath(...parts: string[]): string {
  return parts
    .flatMap((p) => p.split("/"))
    .map((p) => p.trim())
    .filter((p) => p !== "")
    .join("/");
}

/** Absolute-ish folder path for a folder row, walking up to the root. */
export function folderChain(folders: Folder[], folderId: string | null): string | null {
  if (!folderId) return null;
  const byId = new Map(folders.map((f) => [f.id, f]));
  const names: string[] = [];
  const seen = new Set<string>();
  let cur: string | null = folderId;
  while (cur) {
    if (seen.has(cur)) break; // corrupt parent cycle: stop, never hang
    seen.add(cur);
    const f = byId.get(cur);
    if (!f) break;
    names.unshift(fileSegment(f.name, "folder"));
    cur = f.parentId;
  }
  return names.length ? names.join("/") : null;
}

/** `props.day` of a note (daily notes) or null. */
export function dayOfNote(note: Note): string | null {
  const raw = note.props?.day;
  return typeof raw === "string" && DAY_RE.test(raw) ? raw : null;
}

export function pathFor(
  kind: MirrorKind,
  row: Note | Doc | Spec | Task,
  folderPath: string | null = null,
): string {
  switch (kind) {
    case "note": {
      const note = row as Note;
      const day = dayOfNote(note);
      if (day) return assertRelativeVaultPath(`daily/${day}.md`);
      const dir = joinVaultPath("notes", folderPath ?? "");
      return assertRelativeVaultPath(`${dir}/${fileSegment(note.title)}.md`);
    }
    case "doc": {
      const doc = row as Doc;
      const dir = joinVaultPath("docs", fileSegment(doc.category || "general", "general"));
      return assertRelativeVaultPath(`${dir}/${fileSegment(doc.title)}.md`);
    }
    case "spec": {
      const spec = row as Spec;
      return assertRelativeVaultPath(
        `specs/${fileSegment(spec.number || "RFC", "RFC")}-${fileSegment(spec.title)}.md`,
      );
    }
    case "task":
      return assertRelativeVaultPath(`tasks/${fileSegment((row as Task).title)}.md`);
  }
}

/** Which mirror kind a mirror-relative path claims (by its first directory). */
export function claimOf(rel: string): MirrorKind | null {
  const dir = rel.split("/")[0];
  if (dir === "notes" || dir === "daily") return "note";
  if (dir === "docs") return "doc";
  if (dir === "specs") return "spec";
  if (dir === "tasks") return "task";
  return null;
}

/** A `.md` file inside one of the mirror directories. */
export function isMirroredPath(rel: string): boolean {
  if (!rel.endsWith(".md")) return false;
  return (MIRROR_DIRS as readonly string[]).includes(rel.split("/")[0]);
}

/**
 * Make paths unique (case-insensitively — Windows): the first entity keeps the
 * natural path, later collisions get `-2`, `-3`, … before the extension.
 */
export function uniquePaths<T extends { path: string }>(entries: T[]): T[] {
  const taken = new Set<string>();
  return entries.map((entry) => {
    assertRelativeVaultPath(entry.path);
    let path = entry.path;
    if (taken.has(path.toLowerCase())) {
      const m = /^(.*?)(\.[A-Za-z0-9]+)$/.exec(path);
      const base = m ? m[1] : path;
      const ext = m ? m[2] : "";
      let n = 2;
      do {
        path = `${base}-${n}${ext}`;
        n += 1;
      } while (taken.has(path.toLowerCase()));
    }
    taken.add(path.toLowerCase());
    return { ...entry, path };
  });
}
```

```ts
  return Object.fromEntries(Object.entries(obj).filter(([, v]) => v !== undefined)) as T;
}

function unknownProps(props: Record<string, PropValue> | undefined): Record<string, PropValue> {
  return propsFromFields(props ?? {});
}

const isNoteType = (v: string): v is NoteType => (NOTE_TYPES as readonly string[]).includes(v);

/** Frontmatter-only fields per kind (body comes from `bodyOf`). */
function kindFields(kind: MirrorKind, row: Note | Doc | Spec | Task): Record<string, PropValue | undefined> {
  switch (kind) {
    case "note":
      return { type: (row as Note).type };
    case "doc":
      return { category: (row as Doc).category };
    case "spec": {
      const s = row as Spec;
      return { number: s.number, status: s.status, progress: s.implementationProgress };
    }
    case "task": {
      const t = row as Task;
      return { status: t.status, priority: t.priority };
    }
  }
}

/** Serialize one entity to a complete vault document. */
export function serializeEntity(
  kind: MirrorKind,
  row: Note | Doc | Spec | Task,
  meta: { projectSlug: string },
): string {
  const aliases = Array.isArray(row.props?.aliases) ? (row.props.aliases as string[]) : undefined;
  const fields: Record<string, PropValue | undefined> = {
    title: row.title || "untitled",
    ...kindFields(kind, row),
    ...(kind === "spec" ? {} : { tags: (row as Note | Task).tags }),
    aliases: aliases && aliases.length ? aliases : undefined,
    created: iso(row.createdAt),
    updated: iso(row.updatedAt),
    msf_id: row.id,
    msf_kind: kind,
    msf_project: meta.projectSlug,
    ...unknownProps(row.props),
  };
  return stringifyFrontmatter(fields, bodyOf(kind, row));
}

/** Markdown body of an entity (specs get real sections). */
export function bodyOf(kind: MirrorKind, row: Note | Doc | Spec | Task): string {
  switch (kind) {
    case "note":
      return (row as Note).body;
    case "doc":
      return (row as Doc).body;
    case "task":
      return (row as Task).description;
    case "spec":
      return serializeSpecBody(row as Spec);
  }
}

export function parseVaultDoc(content: string): ParsedVaultDoc {
  const { fields, body } = parseFrontmatter(content);
  const rawKind = asString(fields.msf_kind);
  const kind = (MIRROR_KINDS as readonly string[]).includes(rawKind) ? (rawKind as MirrorKind) : null;
  return {
    fields,
    kind,
    id: asString(fields.msf_id) || null,
    title: asString(fields.title),
    tags: asList(fields.tags),
    aliases: asList(fields.aliases),
    day: asString(fields.day) || null,
    props: propsFromFields(fields),
    body,
  };
}
```

```ts
import {
  NOTE_TYPES, specStatusSchema, taskPrioritySchema, taskStatusSchema,
  type Doc, type Note, type NoteType, type Spec, type Task,
} from "@/lib/db/schema";

export const SPEC_SECTIONS = [
  "Purpose", "Goals", "Features", "Constraints", "Dependencies",
  "Acceptance", "Risks", "Future improvements", "Technical notes",
] as const;
const LIST_SECTIONS = new Set(["Goals", "Features", "Constraints", "Dependencies", "Acceptance", "Risks", "Future improvements"]);

export function serializeSpecBody(spec: Spec): string {
  const lists: Array<[string, string[]]> = [
    ["Goals", spec.goals], ["Features", spec.features], ["Constraints", spec.constraints],
    ["Dependencies", spec.dependencies], ["Acceptance", spec.acceptance],
    ["Risks", spec.risks], ["Future improvements", spec.futureImprovements],
  ];
  return [
    `## Purpose\n\n${spec.purpose}`,
    ...lists.map(([title, items]) => `## ${title}\n\n${items.map((i) => `- ${i}`).join("\n")}`),
    `## Technical notes\n\n${spec.technicalNotes}`,
    "",
  ].join("\n\n");
}

export type SpecSections = Pick<
  Spec,
  "purpose" | "goals" | "features" | "constraints" | "dependencies"
  | "acceptance" | "risks" | "futureImprovements" | "technicalNotes"
>;

export function parseSpecBody(body: string): SpecSections {
  const out: SpecSections = {
    purpose: "", goals: [], features: [], constraints: [], dependencies: [],
    acceptance: [], risks: [], futureImprovements: [], technicalNotes: "",
  };
  const keyOf = (title: string): keyof SpecSections =>
    title === "Goals" ? "goals"
    : title === "Features" ? "features"
    : title === "Constraints" ? "constraints"
    : title === "Dependencies" ? "dependencies"
    : title === "Acceptance" ? "acceptance"
    : title === "Risks" ? "risks"
    : title === "Future improvements" ? "futureImprovements"
    : "purpose";
  const stray: string[] = [];
  let current: keyof SpecSections | null = null;
  let buffer: string[] = [];
  const flush = (): void => {
    const text = buffer.join("\n").trim();
    buffer = [];
    if (!current) {
      if (text) stray.push(text);
      return;
    }
    if (LIST_SECTIONS.has(current === "goals" ? "Goals" : "")) {
      /* unreachable: list sections are handled below by key */
    }
    const listKey = (current === "goals" || current === "features" || current === "constraints"
      || current === "dependencies" || current === "acceptance" || current === "risks"
      || current === "futureImprovements") as boolean;
    if (listKey) {
      out[current as "goals"] = text
        ? text.split("\n").map((l) => l.replace(/^[-*]\s+/, "").trim()).filter(Boolean)
        : [];
      return;
    }
    if (current === "technicalNotes") out.technicalNotes = text;
    else out.purpose = text;
  };
  for (const line of body.replace(/\r\n/g, "\n").split("\n")) {
    const heading = /^##\s+(.+?)\s*$/.exec(line);
    if (heading && (SPEC_SECTIONS as readonly string[]).includes(heading[1])) {
      flush();
      current = keyOf(heading[1]);
      if (heading[1] === "Technical notes") current = "technicalNotes";
      continue;
    }
    buffer.push(line);
  }
  flush();
  if (stray.length) {
    out.technicalNotes = [stray.join("\n\n"), out.technicalNotes].filter(Boolean).join("\n\n");
  }
  return out;
}
```

```ts
/**

export const mirrorKey = (kind: MirrorKind, id: string): string => `${kind}:${id}`;

export interface MirrorEntity {
  kind: MirrorKind;
  id: string;
  path: string;

export type VaultAction =

  | { action: "import"; path: string; kind: MirrorKind; entityId: string; auto: boolean }
  | { action: "conflict"; path: string; kind: MirrorKind; entityId: string; baseHash: string | null }
  | { action: "missing"; path: string; kind: MirrorKind; entityId: string }
  | { action: "repath"; from: string; to: string; kind: MirrorKind; entityId: string; import: boolean }
  | { action: "external"; path: string }
  | { action: "blocked"; path: string; kind: MirrorKind | null; entityId: string | null }

  docs: Doc[];
  specs: Spec[];

  folders: Folder[];

/** Rows the app owns -> mirror entities + the exact content we would write. */
export function collectLocal(input: LocalInput): LocalModel {
  const byEntity = new Map<string, SyncFile>();
  for (const r of input.index) if (r.entityId) byEntity.set(r.entityId, r);
  const folderPaths = new Map<string, string | null>();
  for (const f of input.folders) folderPaths.set(f.id, folderChain(input.folders, f.id));

  const drafted: Array<{ kind: MirrorKind; id: string; path: string; content: string }> = [];
  const push = (kind: MirrorKind, row: Note | Doc | Spec | Task, folderPath: string | null): void => {
    const prev = byEntity.get(row.id);
    drafted.push({
      kind,
      id: row.id,
      path: prev?.path ?? pathFor(kind, row, folderPath), // the recorded path wins
      content: serializeEntity(kind, row, { projectSlug: input.projectSlug }),
    });
  };
  for (const n of input.notes) push("note", n, n.folderId ? folderPaths.get(n.folderId) ?? null : null);
  for (const d of input.docs) push("doc", d, null);
  for (const s of input.specs) push("spec", s, null);
  for (const t of input.tasks) push("task", t, null);

  const entities: MirrorEntity[] = [];
  const contentByKey = new Map<string, string>();
  for (const e of uniquePaths(drafted)) {
    const prev = byEntity.get(e.id);
    const deleted = prev?.status === "deleted";
    entities.push({
      kind: e.kind,
      id: e.id,
      path: e.path,
      hash: hashContent(normalizeMd(e.content)),
      baseHash: prev && !deleted && prev.hash ? prev.hash : null,
      status: prev?.status ?? null,
    });
    contentByKey.set(mirrorKey(e.kind, e.id), e.content);
  }
  return { entities, contentByKey };
}

/** Decide what to do. Deterministic: sorted by path. */
export function planVaultSync(input: {
  entities: MirrorEntity[];
  files: MirrorFile[];
  autoImport: boolean;
}): VaultAction[] {
  const byPath = new Map(input.files.map((f) => [f.path, f]));
  const byId = new Map(input.files.filter((f) => f.msfId).map((f) => [f.msfId as string, f]));
  const actions: VaultAction[] = [];
  const claimed = new Set<string>();

  for (const e of [...input.entities].sort((a, b) => a.path.localeCompare(b.path))) {
    const atPath = byPath.get(e.path);
    const sameId = byId.get(e.id);
    const remote = atPath ?? (sameId && !claimed.has(sameId.path) ? sameId : undefined);
    if (remote && remote.path !== e.path) {
      claimed.add(remote.path);
      actions.push({ action: "repath", from: e.path, to: remote.path, kind: e.kind, entityId: e.id, import: false });
    }
    const path = remote?.path ?? e.path;
    if (remote) claimed.add(remote.path);

    if (remote && remote.hash == null) {
      actions.push({ action: "blocked", path, kind: e.kind, entityId: e.id });
      continue;
    }
    const remoteHash = remote?.hash ?? null;
    if (remoteHash == null && e.status === "deleted") {
      actions.push({ action: "skip", path, kind: e.kind, entityId: e.id, status: "deleted" });
      continue;
    }
    if (remoteHash == null && e.status !== null) {
      actions.push({ action: "missing", path, kind: e.kind, entityId: e.id });
      continue;
    }
    const status = classifyRemoteStatus(e.hash, remoteHash, e.baseHash, e.status !== null);
    if (status === "synced") {
      actions.push({ action: "skip", path, kind: e.kind, entityId: e.id, status });
      continue;
    }
    if (status === "new") {
      actions.push({ action: "write", path, kind: e.kind, entityId: e.id, reason: "create" });
      continue;
    }
    if (status === "local_modified") {
      actions.push({ action: "write", path, kind: e.kind, entityId: e.id, reason: "update" });
      continue;
    }
    if (status === "remote_modified") {
      actions.push({ action: "import", path, kind: e.kind, entityId: e.id, auto: input.autoImport });
      continue;
    }
    actions.push({ action: "conflict", path, kind: e.kind, entityId: e.id, baseHash: e.baseHash });
  }

  for (const f of [...input.files].sort((a, b) => a.path.localeCompare(b.path))) {
    if (claimed.has(f.path)) continue;
    actions.push(isMirroredPath(f.path) ? { action: "external", path: f.path } : { action: "ignore", path: f.path });
  }
  return actions;
}

/** The index row an action leaves behind (null = keep whatever was there). */
export function indexRowFor(
  action: VaultAction,
  entity: MirrorEntity | undefined,
  fileHash: string | null,
  now: number,
): SyncFileInput | null {
  switch (action.action) {
    case "write":
      return entity
        ? { path: action.path, hash: entity.hash, status: "synced", entityType: action.kind, entityId: action.entityId, lastSyncedAt: now }
        : null;
    case "import":
      return fileHash
        ? { path: action.path, hash: fileHash, status: "synced", entityType: action.kind, entityId: action.entityId, lastSyncedAt: now }
        : null;
    case "skip":
      return entity
        ? {
            path: action.path, hash: entity.hash, status: action.status,
            entityType: action.kind, entityId: action.entityId,
            lastSyncedAt: entity.status === "deleted" ? null : entity.baseHash ? now : null,
          }
        : null;
    case "repath":
      return entity
        ? { path: action.to, hash: entity.hash, status: "synced", entityType: action.kind, entityId: action.entityId, lastSyncedAt: now }
        : null;
    case "conflict":
    case "blocked":
      return entity
        ? {
            path: entity.path, hash: entity.baseHash ?? entity.hash, status: "conflict",
            entityType: entity.kind, entityId: entity.id, lastSyncedAt: null,
          }
        : null;
    case "missing":
      return { path: action.path, hash: "", status: "deleted", entityType: action.kind, entityId: action.entityId, lastSyncedAt: null };
    case "external":
    case "ignore":
      return null;
  }
}

/** Apply a user's conflict choice to the index row. */
export function resolveNextRow(
  row: SyncFile,
  fileHash: string | null,
  choice: "app" | "file" | "recreate",
  now: number,
): SyncFileInput {
  const base = { path: row.path, entityType: row.entityType, entityId: row.entityId };
  if (choice === "app") {
    return { ...base, hash: fileHash ?? row.hash, status: "local_modified", lastSyncedAt: now };
  }
  if (choice === "file") {
    return { ...base, hash: fileHash ?? row.hash, status: "synced", lastSyncedAt: now };
  }
  return { ...base, hash: "", status: "new", lastSyncedAt: null };
}
```

```ts
import { assertRelativeVaultPath } from "./paths";

/**
 * The vault's disk transport: the P2-confined /api/fs routes. Every path is
 * validated here BEFORE a request is built, so a bug upstream cannot escape the
 * chosen root even if the server had no guard of its own.
 */

export interface VaultListEntry {
  path: string;
  size: number;
  mtime: number;
}

export interface VaultIO {
  list(root: string, folder: string): Promise<{ ok: boolean; files: VaultListEntry[]; error?: string }>;
  read(root: string, path: string): Promise<{ ok: boolean; found: boolean; content: string; truncated: boolean; error?: string }>;
  write(root: string, path: string, content: string): Promise<{ ok: boolean; error?: string }>;
}

/** Mirror files bigger than this are treated as unreadable (the read route caps at 512 KB). */
export const MAX_MIRROR_BYTES = 512 * 1024;
/** The write route rejects > 1 MB. */
export const MAX_WRITE_BYTES = 900 * 1024;
export const MAX_MIRROR_FILES = 2000;

async function post(url: string, body: unknown): Promise<Record<string, unknown>> {
  const res = await fetch(url, {
    method: "POST",
    headers: { "content-type": "application/json" },
    body: JSON.stringify(body),
  });
  const json = (await res.json().catch(() => ({}))) as Record<string, unknown>;
  if (!res.ok && json.error === undefined) json.error = `HTTP ${res.status}`;
  return json;
}

export function createVaultIO(): VaultIO {
  return {
    async list(root, folder) {
      try {
        const json = await post("/api/fs/list", { root, path: folder, depth: 6, maxEntries: MAX_MIRROR_FILES });
        if (!json.ok) return { ok: false, files: [], error: String(json.error ?? "list failed") };
        const prefix = `${folder.replace(/\/+$/, "")}/`;
        const files = ((json.entries as Array<{ path: string; type: string; size: number; mtime: number }>) ?? [])
          .filter((e) => e.type === "file" && e.path.startsWith(prefix) && e.path.toLowerCase().endsWith(".md"))
          .map((e) => ({ path: e.path.slice(prefix.length), size: e.size, mtime: e.mtime }))
          .slice(0, MAX_MIRROR_FILES);
        return { ok: true, files };
      } catch (e) {
        return { ok: false, files: [], error: e instanceof Error ? e.message : String(e) };
      }
    },

    async read(root, path) {
      const rel = assertRelativeVaultPath(path);
      try {
        const json = await post("/api/fs/read", { root, path: rel, maxBytes: MAX_MIRROR_BYTES });
        if (!json.ok) return { ok: false, found: false, content: "", truncated: false, error: String(json.error ?? "read failed") };
        const binary = json.binary === true;
        const truncated = json.truncated === true;
        const content = binary || truncated ? "" : String(json.content ?? "");
        return { ok: true, found: true, content, truncated: binary || truncated };
      } catch (e) {
        return { ok: false, found: false, content: "", truncated: false, error: e instanceof Error ? e.message : String(e) };
      }
    },

    async write(root, path, content) {
      const rel = assertRelativeVaultPath(path);
      if (new TextEncoder().encode(content).length > MAX_WRITE_BYTES) {
        return { ok: false, error: `refusing to write ${rel}: over ${MAX_WRITE_BYTES} bytes` };
      }
      try {
        const json = await post("/api/fs/write", { root, path: rel, content });
        return json.ok ? { ok: true } : { ok: false, error: String(json.error ?? "write failed") };
      } catch (e) {
        return { ok: false, error: e instanceof Error ? e.message : String(e) };
      }
    },
  };
}
```

```ts
export function makeFakeIO(initial: Record<string, string> = {}): {
  io: VaultIO;
  files: Map<string, string>;
  lastRead: { path: string }[];
} {
  const files = new Map(Object.entries(initial));
  const lastRead: { path: string }[] = [];
  const MAX = 512 * 1024;
  const io: VaultIO = {
    async list(_root, folder) {
      const prefix = `${folder}/`;
      const out = [...files.keys()]
        .filter((p) => p.startsWith(prefix))
        .map((p) => ({ path: p.slice(prefix.length), size: files.get(p)!.length, mtime: 0 }));
      return { ok: true, files: out };
    },
    async read(_root, p) {
      lastRead.push({ path: p });
      const content = files.get(p);
      if (content === undefined) return { ok: false, found: false, content: "", truncated: false, error: "ENOENT" };
      const truncated = content.length > MAX;
      return { ok: true, found: true, content: truncated ? "" : content, truncated };
    },
    async write(_root, p, content) {
      files.set(p, content);
      return { ok: true };
    },
  };
  return { io, files, lastRead };
}
```

```ts
import { docsRepo } from "@/lib/db/repos/docs";

import { notesRepo } from "@/lib/db/repos/notes";

import {

import type { SyncFileInput } from "@/lib/db/repos/sync";

export interface VaultDeps {
  io: VaultIO;
  /** absolute folder the user picked (an allowed root) */
  root: string;
  /** mirror subfolder inside it, e.g. `MasarFlow/my-project` */
  folder: string;
  projectId: string;
  projectSlug: string;
  /** import file edits automatically, or only when the user asks */
  autoImport: boolean;
  now: () => number;
  /** safety valve for a folder full of foreign files */
  maxExternalPerRun?: number;
}

export interface VaultRunSummary {
  written: number;
  imported: number;
  conflicts: number;
  missing: number;
  external: number;
  blocked: number;
  skipped: number;
  errors: string[];
}

interface Ctx {
  entities: MirrorEntity[];
  contentByKey: Map<string, string>;
  rows: SyncFileInput[];
  index: SyncFile[];
}

const emptySummary = (): VaultRunSummary => ({
  written: 0, imported: 0, conflicts: 0, missing: 0, external: 0, blocked: 0, skipped: 0, errors: [],
});

/** Read every mirrored .md and describe it (hash null = unreadable). */
async function scanMirror(deps: VaultDeps): Promise<{ files: MirrorFile[]; errors: string[] }> {
  const listed = await deps.io.list(deps.root, deps.folder);
  if (!listed.ok) return { files: [], errors: [listed.error ?? "vault list failed"] };
  const files: MirrorFile[] = [];
  const errors: string[] = [];
  for (const entry of listed.files) {
    if (!isMirroredPath(entry.path)) {
      files.push({ path: entry.path, hash: null, msfId: null });
      continue;
    }
    const read = await deps.io.read(deps.root, `${deps.folder}/${entry.path}`);
    if (!read.ok || !read.found) {
      errors.push(`unreadable: ${entry.path}`);
      files.push({ path: entry.path, hash: null, msfId: null });
      continue;
    }
    if (read.truncated) {
      errors.push(`too large to verify, left untouched: ${entry.path}`);
      files.push({ path: entry.path, hash: null, msfId: null });
      continue;
    }
    files.push({ path: entry.path, hash: hashContent(normalizeMd(read.content)), msfId: parseVaultDoc(read.content).id });
  }
  return { files, errors };
}

async function importEntity(deps: VaultDeps, action: Extract<VaultAction, { action: "import" }>, fileHash: string | null): Promise<boolean> {
  const read = await deps.io.read(deps.root, `${deps.folder}/${action.path}`);
  if (!read.ok || !read.found || read.truncated) {
    deps.io; // no-op, keeps the signature honest for future batching
    return false;
  }
  const patch = applyVaultDoc(action.kind, parseVaultDoc(read.content));
  switch (patch.kind) {
    case "note":
      await notesRepo.update(action.entityId, patch.patch);
      break;
    case "doc":
      await docsRepo.update(action.entityId, patch.patch);
      break;
    case "spec":
      await specsRepo.update(action.entityId, patch.patch);
      break;
    case "task":
      await tasksRepo.update(action.entityId, patch.patch);
      break;
  }
  return fileHash != null;
}

/** Create an entity for a file no row claims (see D-P7-1 for the kinds). */
async function adoptExternal(deps: VaultDeps, path: string): Promise<{ kind: MirrorKind; id: string } | null> {
  const kind = claimOf(path);
  if (!kind) return null;
  const read = await deps.io.read(deps.root, `${deps.folder}/${path}`);
  if (!read.ok || !read.found || read.truncated) return null;
  const doc = parseVaultDoc(read.content);
  const title = doc.title || fileSegment(path.split("/").pop()!.replace(/\.md$/i, ""), "untitled");
  const folderPath = path.split("/").slice(1, -1).join("/");
  if (kind === "note" || kind === "doc") {
    const created =
      kind === "note"
        ? await notesRepo.create({ projectId: deps.projectId, title, body: doc.body, tags: doc.tags })
        : await docsRepo.create({ projectId: deps.projectId, title, body: doc.body, category: folderPath || "general" });
    if (Object.keys(doc.props).length) {
      const patch = { props: doc.props };
      if (kind === "note") await notesRepo.update(created.id, patch);
      else await docsRepo.update(created.id, patch);
    }
    return { kind, id: created.id };
  }
  if (kind === "spec") {
    const created = await specsRepo.create({
      projectId: deps.projectId, title, number: doc.day ?? "RFC", status: undefined,
    } as never);
    return { kind, id: created.id };
  }
  const created = await tasksRepo.create({ projectId: deps.projectId, title, description: doc.body, tags: doc.tags });
  return { kind, id: created.id };
}

export async function runVaultSync(deps: VaultDeps): Promise<VaultRunSummary> {
  const summary = emptySummary();
  const [notes, docs, specs, tasks, folders, index] = await Promise.all([
    notesRepo.listByProject(deps.projectId),
    docsRepo.listByProject(deps.projectId),
    specsRepo.listByProject(deps.projectId),
    tasksRepo.listByProject(deps.projectId),
    foldersRepo.listByProject(deps.projectId),
    syncRepo.listByProject(deps.projectId),
  ]);

  const { entities, contentByKey } = collectLocal({ notes, docs, specs, tasks, folders, index, projectSlug: deps.projectSlug });
  const ctx: Ctx = { entities, contentByKey, rows: [], index };
  const byId = new Map(entities.map((e) => [e.id, e]));
  const { files, errors } = await scanMirror(deps);
  summary.errors.push(...errors);

  const actions = planVaultSync({ entities, files, autoImport: deps.autoImport });
  const fileHashes = new Map(files.map((f) => [f.path, f.hash]));
  const externalLimit = deps.maxExternalPerRun ?? 200;
  let adopted = 0;

  for (const action of actions) {
    switch (action.action) {
      case "write": {
        const content = contentByKey.get(mirrorKey(action.kind, action.entityId));
        if (content === undefined) {
          summary.errors.push(`no content for ${action.entityId}`);
          break;
        }
        const res = await deps.io.write(deps.root, `${deps.folder}/${action.path}`, content);
        if (!res.ok) {
          summary.errors.push(res.error ?? `write failed: ${action.path}`);
          break;
        }
        summary.written += 1;
        break;
      }
      case "import": {
        const ok = await importEntity(deps, action, fileHashes.get(action.path) ?? null);
        if (ok) summary.imported += 1;
        else summary.errors.push(`import failed: ${action.path}`);
        break;
      }
      case "repath":
        break; // the row below carries the new path; content decisions are separate actions
      case "external": {
        if (adopted >= externalLimit) {
          summary.errors.push(`adopt limit reached (${externalLimit}), skipped ${action.path}`);
          break;
        }
        adopted += 1;
        const created = await adoptExternal(deps, action.path);
        if (created) {
          summary.external += 1;
          summary.errors.push(`imported ${action.path} as a new ${created.kind}`);
        } else {
          summary.errors.push(`could not adopt ${action.path}`);
        }
        break;
      }
      case "conflict":
        summary.conflicts += 1;
        break;
      case "blocked":
        summary.blocked += 1;
        break;
      case "missing":
        summary.missing += 1;
        break;
      case "ignore":
        break;
      case "skip":
        summary.skipped += 1;
        break;
    }
    const row = indexRowFor(action, byId.get("entityId" in action ? action.entityId : ""), fileHashes.get(action.path) ?? null, deps.now());
    if (row) ctx.rows.push(row);
  }

  // Rows for entities whose file we adopted/created stay accurate: rewrite them
  // from what we know now (an import may have changed the entity's own hash).
  if (ctx.rows.length) await syncRepo.replaceAll(deps.projectId, ctx.rows);
  return summary;
}

/** The user's answer to a conflict / deletion. */
export async function resolveVaultConflict(
  deps: VaultDeps,
  entityId: string,
  choice: "app" | "file" | "recreate",
): Promise<boolean> {
  const index = await syncRepo.listByProject(deps.projectId);
  const row = index.find((r) => r.entityId === entityId);
  if (!row) return false;
  const read = await deps.io.read(deps.root, `${deps.folder}/${row.path}`);
  const fileHash = read.ok && read.found && !read.truncated ? hashContent(normalizeMd(read.content)) : null;

  if (choice === "file") {
    if (fileHash == null) return false;
    const kind = claimOf(row.path) ?? (row.entityType as MirrorKind | null);
    if (!kind) return false;
    const patch = applyVaultDoc(kind, parseVaultDoc(read.content));
    if (patch.kind === "note") await notesRepo.update(entityId, patch.patch);
    if (patch.kind === "doc") await docsRepo.update(entityId, patch.patch);
    if (patch.kind === "spec") await specsRepo.update(entityId, patch.patch);
    if (patch.kind === "task") await tasksRepo.update(entityId, patch.patch);
  }

  const next = resolveNextRow(row, fileHash, choice, deps.now());
  await syncRepo.replaceAll(
    deps.projectId,
    index.map((r) => (r.id === row.id ? next : { path: r.path, hash: r.hash, status: r.status, entityType: r.entityType, entityId: r.entityId, lastSyncedAt: r.lastSyncedAt })),
  );
  return true;
}
```

```ts
import type { SyncFile } from "@/lib/db/schema";
import type { SyncStatus } from "@/lib/sync";
import type { VaultRunSummary } from "./engine";

/** Everything the vault UI derives from the file index (no React in here). */

export function countByStatus(rows: SyncFile[]): Record<SyncStatus, number> {
  const counts: Record<SyncStatus, number> = {
    synced: 0, local_modified: 0, remote_modified: 0, conflict: 0, new: 0, deleted: 0,
  };
  for (const r of rows) counts[r.status] += 1;
  return counts;
}

/** Rows the user must decide about, in the order they should look. */
export function vaultConflicts(rows: SyncFile[]): SyncFile[] {
  const rank: Partial<Record<SyncStatus, number>> = { conflict: 0, deleted: 1 };
  return rows
    .filter((r) => rank[r.status] !== undefined)
    .sort((a, b) => (rank[a.status] ?? 9) - (rank[b.status] ?? 9) || a.path.localeCompare(b.path));
}

const RANK: Partial<Record<SyncStatus, number>> = { conflict: 0, deleted: 1, local_modified: 2, remote_modified: 3, new: 4, synced: 5 };

export function visibleRows(rows: SyncFile[], filter: SyncStatus | "all"): SyncFile[] {
  const list = filter === "all" ? rows : rows.filter((r) => r.status === filter);
  return [...list].sort((a, b) => (RANK[a.status] ?? 9) - (RANK[b.status] ?? 9) || a.path.localeCompare(b.path));
}

export function vaultSummaryLine(summary: VaultRunSummary): string {
  const parts: string[] = [];
  if (summary.written) parts.push(`${summary.written} written`);
  if (summary.imported) parts.push(`${summary.imported} imported`);
  if (summary.external) parts.push(`${summary.external} new file${summary.external === 1 ? "" : "s"}`);
  if (summary.conflicts) parts.push(`${summary.conflicts} conflict${summary.conflicts === 1 ? "" : "s"}`);
  if (summary.missing) parts.push(`${summary.missing} deleted on disk`);
  if (summary.skipped) parts.push(`${summary.skipped} unchanged`);
  if (summary.errors.length) parts.push(`${summary.errors.length} warning${summary.errors.length === 1 ? "" : "s"}`);
```

```ts
const FOCUS_STALE_MS = 30_000;

export interface VaultSyncApi {
  binding: VaultBinding;
  running: boolean;
  summary: VaultRunSummary | null;
  message: string;
  run: (opts?: { autoImport?: boolean }) => Promise<VaultRunSummary | null>;
  resolve: (entityId: string, choice: "app" | "file" | "recreate") => Promise<void>;
  pickFolder: () => Promise<string | null>;
  setBinding: (root: string) => void;
  setFlags: (patch: Partial<Pick<VaultBinding, "enabled" | "autoImport">>) => void;
  unbind: () => void;
}

/** Bind a folder, run the mirror, answer conflicts. One place, one busy flag. */
export function useVaultSync(projectId: string | null, projectSlug: string): VaultSyncApi {
  const ioRef = useRef<VaultIO>(createVaultIO());
  const binding = useVaultStore((s) => (projectId ? s.byProject[projectId] ?? DEFAULT_BINDING : DEFAULT_BINDING));
  const [running, setRunning] = useState(false);
  const [summary, setSummary] = useState<VaultRunSummary | null>(null);
  const [message, setMessage] = useState("");

  const depsFor = useCallback(
    (over?: Partial<VaultDeps>): VaultDeps | null => {
      const b = vaultBindingFor(projectId);
      if (!projectId || !b.root || !b.folder) return null;
      return {
        io: ioRef.current,
        root: b.root,
        folder: b.folder,
        projectId,
        projectSlug,
        autoImport: b.autoImport,
        now: () => Date.now(),
        ...over,
      };
    },
    [projectId, projectSlug],
  );

  const run = useCallback<VaultSyncApi["run"]>(
    async (opts) => {
      const deps = depsFor(opts?.autoImport === undefined ? undefined : { autoImport: opts.autoImport });
      if (!deps) {
        setMessage("Pick a folder for this project first.");
        return null;
      }
      setRunning(true);
      try {
        const result = await runVaultSync(deps);
        setSummary(result);
        const line = vaultSummaryLine(result);
        setMessage(line);
        useVaultStore.getState().patch(deps.projectId, { lastRunAt: Date.now(), lastSummary: line });
        return result;
      } catch (e) {
        setMessage(e instanceof Error ? e.message : String(e));
        return null;
      } finally {
        setRunning(false);
      }
    },
    [depsFor],
  );

  const resolve = useCallback<VaultSyncApi["resolve"]>(
    async (entityId, choice) => {
      const deps = depsFor();
      if (!deps) return;
      try {
        await resolveVaultConflict(deps, entityId, choice);
        await run();
      } catch (e) {
        setMessage(e instanceof Error ? e.message : String(e));
      }
    },
    [depsFor, run],
  );

  const pickFolder = useCallback(async () => {
    const api = getDesktop();
    const picked = (await api?.dialog?.chooseFolder?.()) ?? null;
    // Browser dev fallback: the user types a path and /api/fs validates it (P2).
    if (!picked) return null;
    setBinding(picked);
    return picked;
  }, []);

  const setBinding = useCallback(
    (root: string) => {
      if (!projectId) return;
      useVaultStore.getState().bind(projectId, root, projectSlug);
    },
    [projectId, projectSlug],
  );

  const setFlags = useCallback<VaultSyncApi["setFlags"]>(
    (patch) => {
      if (!projectId) return;
      useVaultStore.getState().patch(projectId, patch);
    },
    [projectId],
  );

  const unbind = useCallback(() => {
    if (projectId) useVaultStore.getState().unbind(projectId);
  }, [projectId]);

  useEffect(() => {
    if (!binding.enabled || !binding.root || !projectId) return;
    let cancelled = false;
    const tick = (): void => {
      if (!cancelled) void run();
    };
    tick();
    const id = window.setInterval(tick, AUTO_SYNC_MS);
    const onFocus = (): void => {
      if (Date.now() - (vaultBindingFor(projectId).lastRunAt ?? 0) > FOCUS_STALE_MS) tick();
    };
    window.addEventListener("focus", onFocus);
    return () => {
      cancelled = true;
      window.clearInterval(id);
      window.removeEventListener("focus", onFocus);
    };
  }, [binding.enabled, binding.root, projectId, run]);

  return { binding, running, summary, message, run, resolve, pickFolder, setBinding, setFlags, unbind };
}
```

```ts
import type { PropValue } from "@/lib/db/schema";
import { RESERVED_KEYS } from "./serialize";

/**
 * Frontmatter properties as UI rows. `aliases` is the one key that is reserved
 * in the FILE but a normal property in the entity, so it stays editable here —
 * that is how the user maintains the aliases `[[Alias]]` resolves through.
 */
export const PROP_BLOCKLIST: ReadonlySet<string> = new Set(RESERVED_KEYS.filter((k) => k !== "aliases"));

export type PropKind = "text" | "number" | "boolean" | "list";

export interface PropRow {
  key: string;
  value: PropValue;
  kind: PropKind;
}

export function propKind(v: PropValue): PropKind {
  if (Array.isArray(v)) return "list";
  if (typeof v === "number") return "number";
  if (typeof v === "boolean") return "boolean";
  return "text";
}

export function toPropRows(props: Record<string, PropValue> | undefined): PropRow[] {
  return Object.entries(props ?? {})
    .filter(([k]) => !PROP_BLOCKLIST.has(k))
    .map(([key, value]) => ({ key, value, kind: propKind(value) }));
}

export function fromPropRows(rows: PropRow[]): Record<string, PropValue> {
  const out: Record<string, PropValue> = {};
  for (const row of rows) {
    const key = row.key.trim();
    if (!key || PROP_BLOCKLIST.has(key)) continue;
    if (Array.isArray(row.value)) {
      if (row.value.length) out[key] = row.value;
      continue;
    }
    if (typeof row.value === "string") {
      if (row.value.trim() !== "") out[key] = row.value;
      continue;
    }
    out[key] = row.value;
  }
  return out;
}

export function parsePropInput(raw: string, kind: PropKind): PropValue {
  const text = raw.trim();
  if (kind === "number") {
    const n = Number(text);
    return text !== "" && Number.isFinite(n) ? n : text;
  }
  if (kind === "boolean") return text === "true";
  if (kind === "list") return text.split(",").map((p) => p.trim()).filter(Boolean);
  return text;
}

export const addPropRow = (rows: PropRow[], key = ""): PropRow[] => [...rows, { key, value: "", kind: "text" }];
export const removePropRow = (rows: PropRow[], index: number): PropRow[] => rows.filter((_, i) => i !== index);
export const renamePropRow = (rows: PropRow[], index: number, key: string): PropRow[] =>
  rows.map((r, i) => (i === index ? { ...r, key } : r));
export function setPropValue(rows: PropRow[], index: number, raw: string): PropRow[] {
  return rows.map((r, i) => {
    if (i !== index) return r;
    const value = parsePropInput(raw, r.kind);
    return { ...r, value, kind: propKind(value) };
  });
}
```

```ts
// A tag starts with a letter/underscore, may contain letters, digits, `_`, `-`
// and `/` (nested tags), and must not be preceded by a word character or `/`
// (so `issue#1` and URLs with fragments are not tags — same rule as Obsidian).
const TAG_RE = /(?:^|[\s(])#([\p{L}_][\p{L}\p{N}_/-]*)/gu;

/** Inline `#tag` references, de-duplicated case-insensitively, in order. */
export function extractTags(markdown: string): string[] {
  const seen = new Set<string>();
  const tags: string[] = [];
  for (const match of markdown.matchAll(TAG_RE)) {
    const tag = match[1].replace(/[-/]+$/, "");
    if (!tag || !/\p{L}/u.test(tag)) continue;
    const key = tag.toLowerCase();
    if (seen.has(key)) continue;
    seen.add(key);
    tags.push(tag);
  }
  return tags;
}
```

```ts
import Fuse from "fuse.js";
import type { Doc, Note, Spec, Task } from "@/lib/db/schema";
import { docsRepo, notesRepo, specsRepo, tasksRepo } from "@/lib/db/repos";
import { entityHref } from "@/lib/entities/registry"; // P5.T1
import type { MirrorKind } from "./paths";

/** The Ctrl/Cmd+O palette: everything the vault mirrors, searchable. */

export const KIND_LABEL: Record<MirrorKind, string> = {
  note: "Note",
  doc: "Doc",
  spec: "Spec",
  task: "Task",
};

export interface QuickItem {
  kind: MirrorKind;
  id: string;
  title: string;
  subtitle: string;
  href: string;
  updatedAt: number;
}

function makeItem(
  kind: MirrorKind,
  row: { id: string; title: string; updatedAt: number },
  badge: string | undefined,
  tags: string[],
): QuickItem {
  return {
    kind,
    id: row.id,
    title: row.title || "untitled",
    subtitle: [KIND_LABEL[kind], badge, tags.slice(0, 3).join(" ")].filter(Boolean).join(" · "),
    href: entityHref({ kind, id: row.id }),
    updatedAt: row.updatedAt,
  };
}

export function buildQuickItems(input: { notes: Note[]; docs: Doc[]; specs: Spec[]; tasks: Task[] }): QuickItem[] {
  return [
    ...input.notes.map((n) => makeItem("note", n, n.type, n.tags)),
    ...input.docs.map((d) => makeItem("doc", d, d.category, [])),
    ...input.specs.map((s) => makeItem("spec", s, s.status, [])),
    ...input.tasks.map((t) => makeItem("task", t, t.status, t.tags)),
  ].sort((a, b) => b.updatedAt - a.updatedAt || a.title.localeCompare(b.title));
}

export function rankQuickItems(items: QuickItem[], query: string, limit = 12): QuickItem[] {
  const q = query.trim();
  if (!q) return items.slice(0, limit);
  const fuse = new Fuse(items, {
    keys: ["title", "subtitle"],
    threshold: 0.35,
    ignoreLocation: true,
  });
  return fuse.search(q, { limit }).map((r) => r.item);
}

export async function loadQuickItems(projectId: string): Promise<QuickItem[]> {
  const [notes, docs, specs, tasks] = await Promise.all([
    notesRepo.listByProject(projectId),
    docsRepo.listByProject(projectId),
    specsRepo.listByProject(projectId),
    tasksRepo.listByProject(projectId),
  ]);
  return buildQuickItems({ notes, docs, specs, tasks });
}
```

```ts
export const DAILY_TAG = "daily";

/** `YYYY-MM-DD` in the user's local timezone (a day is a local thing). */
export function dayKey(date: Date): string {
  const y = date.getFullYear();
  const m = String(date.getMonth() + 1).padStart(2, "0");
  const d = String(date.getDate()).padStart(2, "0");
  return `${y}-${m}-${d}`;
}

export const dailyTitle = (day: string): string => day;

/** The file the day maps to (guarded in paths.ts). */
export function dailyPathKey(day: string): string {
  return `daily/${day}.md`;
}

export function dailyNoteProps(day: string): Record<string, PropValue> {
  return { day };
}

export function findDailyNote(notes: Note[], day: string): Note | null {
  return notes.find((n) => dayOfNote(n) === day) ?? null;
}

/** Today's note, created on first use. Never duplicates a day. */
export async function ensureDailyNote(projectId: string, day = dayKey(new Date())): Promise<Note> {
  const existing = findDailyNote(await notesRepo.listByProject(projectId), day);
  if (existing) return existing;
  const created = await notesRepo.create({
    projectId,
    title: dailyTitle(day),
    body: "",
    tags: [DAILY_TAG],
    props: dailyNoteProps(day),
  });
  return created;
}

/** Ensure + focus. The one entry point P8's Today view and the palette use. */
export async function openDailyNote(projectId: string, date = new Date()): Promise<{ noteId: string }> {
  const note = await ensureDailyNote(projectId, dayKey(date));
  await openEntity({ kind: "note", id: note.id });
  return { noteId: note.id };
}
```

## Risks / open questions

- **Full-file reads each run (A4).** Every mirrored `.md` is read on every run because `syncFiles.mtime` is repo-stamped, not the file's. At 500 notes over loopback that is ~150 ms; at 5,000 it is seconds. *Follow-up (not P7):* store the real disk mtime and skip unchanged files, which means bypassing `syncRepo.replaceAll`'s `mtime: ts`.
- **Deleting an entity does not delete its file.** `notesRepo.remove` is never observed by the vault, so the file survives as an orphan and re-appears on the next sync as an `external` file — which would re-import it as a *new* note (with a new id). P7 does not fix this; the file is the user's, and P6's recycle-bin work is the natural place. **Decision needed from the user**: adopt, or mark the index row `deleted` for good?
- **`h1` heading style / rename-on-title-change.** We deliberately do not rename files when a title changes (the recorded path wins). A user renaming a title in the app sees the *title property* change but not the filename. Obsidian's own behaviour is configurable; ours is "stable paths, adopt moves".
- **Folder-as-source-of-truth pitfalls.** A note's *folder* is derived from `notes.folderId` at first write, but after that the recorded path wins — so moving a note between folders inside the app does **not** move its file, while moving the *file* inside Obsidian does get adopted (repath). This asymmetry is intentional (an unexpected rename in a git-tracked vault is worse than a stale folder) but it is the most likely source of "why is this note still in `notes/Auth/`?" confusion. Surface it in the panel copy if it bites.
- **Spec/task adoption is lossy at the edges.** A foreign `specs/*.md` becomes a spec with `number: "RFC"` if the file has no `number`; a foreign file under `tasks/` becomes a task in the default status. Both are recoverable in the UI, but the adopt path is deliberately shallow.
- **Two writers, one vault.** The Obsidian REST mode and the disk mirror share the file *format* (D-P7-2) but not the index semantics; running both against the same vault folder is not coordinated in P7. Either bind the vault folder or the Obsidian vault, not both, and P6's sync-unification work should make this impossible to misconfigure.
- **Windows path edge cases.** `fileSegment` strips the hostile set and caps at 64 chars, and `uniquePaths` de-duplicates case-insensitively; a name that is *only* hostile characters falls back to `untitled`, so two such notes become `untitled.md` / `untitled-2.md`. Long-path limits (>260) are still possible for deeply nested note folders — the guard rejects >240-char relative paths before that becomes an OS error, and the run reports it as a warning.
- **Blocked files surface as conflicts.** An unreadable file (truncated >512 KB or binary) produces a `conflict` row the user cannot resolve except by shrinking the file. Deliberate (never overwrite what we cannot verify), but noisy; a future "ignore this file" action belongs with the same follow-up as the mtime optimisation.
- **`autoImport` is off by default** and the "Watch continuously" checkbox is the only trigger for the 60 s interval + focus check. A background watcher driven by `/api/watch` SSE is explicitly out of scope (the endpoint is a feed, and P6 owns sleep/wake).
