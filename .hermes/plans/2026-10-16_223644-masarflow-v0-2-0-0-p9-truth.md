# MasarFlow v0.2.0.0 — P9: Kill fakes + feature truth

> **For Hermes:** execute with `subagent-driven-development`, one task at a time, two-stage review per task. Read the master plan (`…-master.md`) §2 (F1–F12), §3 (release gate), §4 (D10), §6 (conventions), §7 (P9 row) and §10 (P5 → P9 handoffs) before starting.
> **Depends on:** P6 (git/GitHub), P7 (vault), P8 (dock/frontend) — P9 is the *last* phase before the release phase. **Branch:** `release/v0.2.0`.
> **This is plan mode's output:** the phase is *designed* here, not executed. Every command below is meant to be run by the implementing agent, and every "Expected" line is what that agent must see.

**Goal:** Delete or wire every feature that exists in a catalog, route list or settings screen but does not work, and make that truth permanent by machine-checked guards — three shrinking allow-lists that reach `[]`, a feature matrix whose every entry has a passing Playwright test against the **packaged** desktop app, plus accessibility, performance and first-run evidence a first-time user could reproduce.

---

## What "truth" means in this phase — the four rules

1. **A catalog entry must have a consumer.** Every `PluginDef.id` in `PLUGIN_CATALOG` (`src/lib/plugins.ts`) must be referenced by code that actually changes behaviour — either the `usePlugin("<id>")` runtime (`src/lib/plugins-runtime.ts:34`) or an equivalent gate. Otherwise the entry is deleted.
2. **A route must have a caller.** Every `src/app/api/**/route.ts` must be reachable from code in `src/`, `desktop/src/` or `scripts/`; every `src/app/(workspace)/**/page.tsx` must be a dock page (`PAGE_PATHS`, `src/lib/dock/registry.ts:22`) and therefore navigable from the sidebar/dock.
3. **A setting must have a consumer.** Every leaf key of `PAGE_SETTINGS_DEFAULTS` must be read outside the store and the settings screen.
4. **A listed feature must have a passing test that asserts a user-visible outcome**, not that a page rendered. `expect(await page.locator("body").count()).toBe(1)` is forbidden. Every matrix feature title `<route>: <feature>` must exist verbatim in a `tests/e2e/**/*.spec.ts` file and must pass against `desktop/dist/win-unpacked/MasarFlow.exe`.

Follow-on rule (master §6): **no new feature without an entry** in `tests/e2e/feature-matrix.json`; **no entry without a spec**.

## P9.T1 — Truth baseline, evidence script, `reports/` convention (≈8 min)

Purpose: capture the exact pre-state so any later "it was already broken" claim can be checked, and give every task a one-line evidence command.

**Create `reports/README.md`:**

```markdown
# reports/

Committed evidence for phase gates. One directory per phase (`reports/p9/`, `reports/p10/`).

Rules:
- Files here are *records of runs*, not fixtures. Never edit a past run; add a new file with a date.
- JSON for measurements (`perf-baseline.json`, `a11y/summary.json`), Markdown for narratives and checklists.
- Every claim in a report must name the command that produced it.
- `reports/` is intentionally committed (unlike `test-results/` and `playwright-report/`).
```

**Create `scripts/truth-scan.mjs`** (the reproducible version of the four scans; the guard tests remain the gate, this is for humans and reports):

```js

// tests/unit/repo-truth/*.test.ts + tests/unit/lib/plugins-consumers.test.ts.
import { readdirSync, readFileSync, statSync } from "node:fs";
import path from "node:path";
import { fileURLToPath } from "node:url";

const ROOT = path.resolve(path.dirname(fileURLToPath(import.meta.url)), "..");

function walk(dir, exts, out = []) {
  for (const name of readdirSync(dir)) {
    const full = path.join(dir, name);
    if (statSync(full).isDirectory()) {
      if (["node_modules", ".next", "dist", "out", ".git"].includes(name)) continue;
      walk(full, exts, out);
    } else if (exts.some((e) => name.endsWith(e))) out.push(full);
  }
  return out;
}

const rel = (p) => p.replaceAll("\\", "/").replace(ROOT + "/", "");

  dirs
    .filter((d) => { try { return statSync(path.join(ROOT, d)).isDirectory(); } catch { return false; } })
    .flatMap((d) => walk(path.join(ROOT, d), exts))
    .map((p) => ({ path: rel(p), text: readFileSync(p, "utf8") }));

function settings() {

  const anchor = store.indexOf("PAGE_SETTINGS_DEFAULTS: AllPageSettings = {");

  for (let i = start; i < store.length; i++) {
    if (store[i] === "{") depth++;
    else if (store[i] === "}" && --depth === 0) { end = i + 1; break; }
  }

    (s) => s.path !== "src/lib/stores/page-settings.ts" && !s.path.startsWith("src/components/settings/"),
```

```ts
/**
 * The packaged binary. P1 sets productName: MasarFlow in
 * desktop/electron-builder.yml; if that changes, this resolves it from the
 * config instead of failing with a confusing ENOENT.
 */
export function packagedExe(): string {
  const dir = path.join(REPO_ROOT, "desktop", "dist", "win-unpacked");
  const cfg = path.join(REPO_ROOT, "desktop", "electron-builder.yml");
  if (existsSync(cfg)) {
    const m = /^productName:\s*(.+)$/m.exec(readFileSync(cfg, "utf8"));
    const candidate = m ? path.join(dir, `${m[1].trim()}.exe`) : null;
    if (candidate && existsSync(candidate)) return candidate;
  }
  if (existsSync(dir)) {
    const exe = readdirSync(dir)
      .filter((f) => f.toLowerCase().endsWith(".exe"))
      .filter((f) => !/unins|elevate|crashpad/i.test(f))[0];
    if (exe) return path.join(dir, exe);
  }
  throw new Error(
    `No packaged app found in ${dir}. Run: pnpm desktop:dist:dir (≈90 s). ` +
      `The e2e suite never runs against the dev server — that is the point of P9.`,
  );
}

 * localStorage) and `app.getPath("userData")` that the embedded server writes to.
 * MASARFLOW_SMOKE must NOT be set here — it makes the app exit by design.

export async function launchApp(opts: { seed?: "none" | "demo" } = {}): Promise<AppHandle> {
  const profileDir = mkdtempSync(path.join(os.tmpdir(), "masarflow-e2e-"));
  const app = await electron.launch({
```

```ts
import { createServer, type Server } from "node:http";
import type { AddressInfo } from "node:net";

export interface ReceivedCall {
  path: string;
  body: unknown;
}

/**
 * Loopback model server: the minimal surface the app needs.
 * - GET  /api/tags                → Ollama-style model list (used by
 *                                   /api/ollama/models?baseUrl=…)
 * - POST /v1/chat/completions     → OpenAI-shaped completion, non-streaming and
 *                                   SSE streaming, echoing the received prompt
 *                                   so a spec can assert what the app sent.
 */
export async function startStubProvider(): Promise<{
  baseUrl: string;
  calls: ReceivedCall[];
  stop(): Promise<void>;
}> {
  const calls: ReceivedCall[] = [];
  const server: Server = createServer((req, res) => {
    let raw = "";
    req.on("data", (c) => (raw += c));
    req.on("end", () => {
      const path = req.url ?? "/";
      let body: unknown = null;
      try { body = raw ? JSON.parse(raw) : null; } catch { /* ignore */ }
      calls.push({ path, body });

      if (path.startsWith("/api/tags")) {
        res.writeHead(200, { "content-type": "application/json" });
        res.end(JSON.stringify({ models: [{ name: "stub-model", size: 1 }] }));
        return;
      }
      if (path.startsWith("/v1/chat/completions") || path.startsWith("/api/chat")) {
        const messages = (body as { messages?: { role: string; content: string }[] })?.messages ?? [];
        const lastUser = [...messages].reverse().find((m) => m.role === "user")?.content ?? "";
        const replyText = `STUB-REPLY ${lastUser.slice(0, 400)}`;
        const wantsStream = (body as { stream?: boolean })?.stream !== false;
        if (!wantsStream) {
          res.writeHead(200, { "content-type": "application/json" });
          res.end(JSON.stringify({
            id: "stub", object: "chat.completion", model: "stub-model",
            choices: [{ index: 0, message: { role: "assistant", content: replyText }, finish_reason: "stop" }],
          }));
          return;
        }
        res.writeHead(200, { "content-type": "text/event-stream", "cache-control": "no-cache" });
        const chunk = (delta: object, finish: string | null = null) =>
          `data: ${JSON.stringify({ id: "stub", object: "chat.completion.chunk", model: "stub-model", choices: [{ index: 0, delta, finish_reason: finish }] })}\n\n`;
        res.write(chunk({ role: "assistant", content: "" }));
        for (const word of replyText.split(" ")) res.write(chunk({ content: word + " " }));
        res.write(chunk({}, "stop"));
        res.write("data: [DONE]\n\n");
        res.end();
        return;
      }
      res.writeHead(404, { "content-type": "application/json" });
      res.end(JSON.stringify({ error: `stub: no handler for ${path}` }));
    });
  });
  await new Promise<void>((resolve) => server.listen(0, "127.0.0.1", resolve));
  const { port } = server.address() as AddressInfo;
  return {
    baseUrl: `http://127.0.0.1:${port}/v1`,
    calls,
    stop: () => new Promise<void>((resolve) => server.close(() => resolve())),
  };
}
```

```ts
import type { Page } from "@playwright/test";
import { readFileSync } from "node:fs";
import { createRequire } from "node:module";

const require_ = createRequire(import.meta.url);

export interface AxeViolation {
  id: string;
  impact: string | null;
  help: string;
  nodes: number;
}

/**
 * Runs axe-core inside the packaged renderer.
 *
 * Primary path: @axe-core/playwright. Fallback (works with zero peer
 * resolution): inject axe-core's UMD bundle from node_modules and call axe.run.
 * Both return the same shape, so the assertion code does not care which ran.
 */
export async function axeScan(
  page: Page,
  opts: { include?: string[]; tags?: string[] } = {},
): Promise<{ violations: AxeViolation[]; engine: "playwright" | "injected" }> {
  const tags = opts.tags ?? ["wcag2a", "wcag2aa"];
  try {
    const { AxeBuilder } = require_("@axe-core/playwright") as typeof import("@axe-core/playwright");
    const builder = new AxeBuilder({ page }).withTags(tags);
    for (const sel of opts.include ?? []) builder.include(sel);
    const res = await builder.analyze();
    return {
      engine: "playwright",
      violations: res.violations.map((v) => ({
        id: v.id,
        impact: v.impact ?? null,
        help: v.help,
        nodes: v.nodes.length,
      })),
    };
  } catch {
    const axePath = require_.resolve("axe-core/axe.min.js");
    await page.addScriptTag({ path: axePath });
    const raw = await page.evaluate(
      async ({ tags: t, include }) => {
        const axe = (window as unknown as { axe: { run: (ctx: unknown, o: unknown) => Promise<unknown> } }).axe;
        const ctx = include.length ? { include } : undefined;
        const out = (await axe.run(ctx, { runOnly: { type: "tag", values: t } })) as {
          violations: { id: string; impact: string | null; help: string; nodes: unknown[] }[];
        };
        return out.violations.map((v) => ({ id: v.id, impact: v.impact, help: v.help, nodes: v.nodes.length }));
      },
      { tags, include: opts.include ?? [] },
    );
    return { engine: "injected", violations: raw };
  }
}

export const FAILING_IMPACTS = ["serious", "critical"] as const;

export function failing(violations: AxeViolation[]): AxeViolation[] {
  return violations.filter((v) => v.impact && FAILING_IMPACTS.includes(v.impact as never));
}
```

```ts
function p95(values: number[]): number {
  const sorted = [...values].sort((a, b) => a - b);
  return sorted[Math.min(sorted.length - 1, Math.ceil(sorted.length * 0.95) - 1)];
```

## P9.T21 — Memory ceiling after 10 minutes idle (`@slow`) (≈12 min)

Purpose: the one number that catches leaks without a profiler.

**Create `tests/e2e/desktop/soak.spec.ts`:**

```ts
import { test, expect, launchApp, writeEvidence } from "./_harness";
import { BUDGETS } from "./perf-budgets";

test.describe.configure({ mode: "serial" });

/** Main-process RSS via ElectronApplication.evaluate (runs in the main process). */
async function mainRssMb(app: import("@playwright/test").ElectronApplication): Promise<number> {
  const bytes = await app.evaluate(() => process.memoryUsage().rss);
  return Math.round(bytes / 1024 / 1024);
}

/** Renderer JS heap via CDP Performance.getMetrics on the Electron context. */
async function rendererHeapMb(
  app: import("@playwright/test").ElectronApplication,
  page: import("@playwright/test").Page,
): Promise<number> {
  const cdp = await app.context().newCDPSession(page);
  await cdp.send("Performance.enable");
  const { metrics } = await cdp.send("Performance.getMetrics");
  const used = metrics.find((m) => m.name === "JSHeapUsedSize")?.value ?? -1;
  await cdp.detach();
  return Math.round(used / 1024 / 1024);
}

test("@slow perf: memory stays inside the ceiling after 10 minutes idle", async () => {
  test.setTimeout(13 * 60 * 1000); // the config's 180 s default is far too short
  const { app, page, close } = await launchApp({ seed: "demo" });
  try {
    const at2 = { main: await mainRssMb(app), renderer: await rendererHeapMb(app, page) };
    await page.waitForTimeout(8 * 60 * 1000); // 2 min already elapsed → 10 min total
    const at10 = { main: await mainRssMb(app), renderer: await rendererHeapMb(app, page) };
    const growthPct = Math.round(((at10.renderer - at2.renderer) / Math.max(1, at2.renderer)) * 100);
    const record = { at2, at10, growthPct, budgets: BUDGETS.memory };
    writeEvidence("perf-memory-10min.json", record);

    expect(at10.main, `main RSS ${at10.main} MB`).toBeLessThanOrEqual(BUDGETS.memory.mainRssMb);
    expect(at10.renderer, `renderer heap ${at10.renderer} MB`).toBeLessThanOrEqual(BUDGETS.memory.rendererHeapMb);
    expect(growthPct, `heap growth ${growthPct}% over 8 minutes`).toBeLessThanOrEqual(
      BUDGETS.memory.growth2to10MinPct,
    );
  } finally {
    await close();
  }
});
```
